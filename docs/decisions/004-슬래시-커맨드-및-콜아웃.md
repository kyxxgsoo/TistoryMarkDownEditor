# ADR-004: 노션 스타일 슬래시 커맨드 및 콜아웃 블록

> Date: 2026-03-19

## 상황 (Context)
사용자가 노션처럼 `/` 입력으로 블록 타입을 빠르게 선택할 수 있는 UX와, 정보를 강조할 수 있는 콜아웃 블록이 필요하다.

## 선택지 (Options)

### 슬래시 커맨드
1. **@tiptap/suggestion 활용** — TipTap 공식 제안(Suggestion) API 사용. ProseMirror 플러그인 기반, 커서 위치 추적/키보드 네비게이션 내장 / 커스텀 UI 직접 구현 필요
2. **직접 keydown 이벤트 핸들링** — `/` keydown 감지 후 커스텀 팝업 표시 / ProseMirror 트랜잭션과의 동기화가 복잡, 에지 케이스 다수

### 콜아웃 스타일링
1. **CSS 클래스 기반** — 에디터에서는 잘 보이나 발행 후 블로그에 CSS가 없어 스타일 유실
2. **인라인 스타일 기반** — HTML에 스타일이 포함되어 발행 후에도 유지 / HTML이 다소 길어짐

## 결정 (Decision)
- **슬래시 커맨드**: 선택지 1 (@tiptap/suggestion). `command` 콜백에서 `/query` 텍스트를 `deleteRange`로 제거 후 블록 커맨드 실행.
- **콜아웃 스타일링**: 선택지 2 (인라인 스타일). `renderHTML`에서 타입별 배경색/테두리를 inline style로 출력.
- **콜아웃 parseHTML**: `contentElement: 'div:last-child'`로 이모지 span을 콘텐츠에서 제외하여 수정 시 이모지 중복 방지.

## 결과 (Result)
- `/` 입력 시 12개 커맨드 (제목1-3, 리스트, 인용, 코드블록, 구분선, 서식, 콜아웃 4종) 드롭다운 표시
- 한글 검색 필터링 지원 (`/제목` → 제목 관련 항목만)
- 콜아웃은 info/warning/success/danger 4종, 발행 후에도 스타일 유지
- 글 수정 시 콜아웃 이모지 중복 없이 정상 파싱
